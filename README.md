# 📝 Note Manager

Aplicación web para gestionar notas personales, construida con Angular 21.

## 🚀 Características (planeadas)

- ✍️ Crear, editar y eliminar notas
- 🏷️ Categorizar notas por etiquetas
- 🔍 Búsqueda y filtros
- 💾 Persistencia local / API REST
